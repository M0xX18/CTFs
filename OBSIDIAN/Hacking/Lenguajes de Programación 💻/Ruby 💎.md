# CONCEPTO

> **Ruby** es un lenguaje de programación interpretado, orientado a objetos y de propósito general, enfocado en la simplicidad y productividad. Fue diseñado para que el código sea legible y natural, priorizando la experiencia del desarrollador. Es ampliamente utilizado en desarrollo web, automatización y scripting.

------------
## USO:
Para ejecutar un script que esté hecho en **Ruby**, necesitamos tener el intérprete instalado y luego podemos ejecutarlo desde la consola con el siguiente comando:

```BASH
ruby script.rb
```

Si quisiéramos crear un script en **Ruby**, la estructura básica puede incluir el shebang para hacerlo ejecutable directamente en sistemas Unix:

```RUBY
#!/usr/bin/env ruby
puts "Hola, este es mi programa en Ruby"
```

Luego podemos darle permisos y ejecutarlo así:

```BASH
chmod +x script.rb  
./script.rb
```
